# math-sound-visualizer-public
A simple interactive web application demonstrating the connection between mathematical concepts and sound waves using JavaScript. (Note: Project interface and contents are in Arabic).
# Math & Sound Visualizer (الرياضيات والصوت)

An interactive web application created to demonstrate and visualize the relationship between mathematical concepts, frequencies, and sound generation. 

> **Note:** The interface, user instructions, and internal labels of this project are written in **Arabic** (اللغة العربية) to support Arabic-speaking students and educators.

---

## 📌 Project Overview
This tool simplifies how mathematics—such as functions and wave frequencies—transforms into audio tones through an interactive browser experience.

## 🎓 For Students & Educational Use
This project is open-source and free to use for educational purposes. Feel free to fork, customize, or adapt the code for your own school math projects!

## 🛠️ Built With
* **HTML5** - Page structure (Arabic interface).
* **CSS3** - Responsive design and styling.
* **JavaScript** - Mathematical calculations and Web Audio API synthesis.

## 🚀 How to Run
Simply open `index.html` in any web browser, or launch it via GitHub Pages.
